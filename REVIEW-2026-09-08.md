## 1. Ringkasan Eksekutif

Rasamala adalah template OPAC yang **secara umum dikerjakan dengan sangat rapi**: disiplin escaping tinggi, query berparameter, arsitektur helper modular, aset kondisional per halaman, dan aksesibilitas di atas rata-rata template SLiMS.

Namun review kali ini menemukan **2 temuan kritis yang lolos dari review sebelumnya**:

1. **XSS di seluruh template sitasi** (`citation/*.php`) — data katalog (`$title`, `$authors_string`, `$publisher_name`, dll.) dicetak mentah dengan `print`.
2. **Host-header injection** di `detail_template.php` dan `parts/_other.php` — `$_SERVER['HTTP_HOST']` tanpa validasi masuk ke QR code & URL bagikan → vektor phishing.

Ditambah 6 temuan tinggi (termasuk bug fungsional di `themeInjectCspNonceToScripts` yang merusak `const`/`let` lintas-script, kebocoran `csrf_token` ke URL ganti bahasa, dan bypass sanitasi metadata) serta ±20 temuan sedang/rendah, dan satu temuan operasi: **setengah ukuran repo (6 MB dari 12 MB) adalah 500+ file bendera SVG yang hanya ~3 dipakai**.

**Rekomendasi utama:** perbaiki K-01 & K-02 segera (patch contoh tersedia di bawah), lalu kerjakan temuan Tinggi sebelum rilis berikutnya. Tidak ada alasan untuk menahan pemakaian template ini setelah patch kritis diterapkan.

## 3. Temuan Kritis 🔴

### K-01 — XSS di semua template sitasi (`citation/*.php`)

**Lokasi:**

- `citation/apa_style_template.php:161-167`
- `citation/chicago_style_template.php:23-33`
- `citation/mla_style_template.php:57-67`
- `citation/turabian_style_template.php:26-34`

**Bukti (APA):**

```php
<span class="authors"><?php print $authors_string ?></span>
<span class="title"><em><?php print $title ?></em> ...
<span class="publish_place"><?php print $publish_place ?>:</span>
<span class="publisher"><?php print $publisher_name ?>.</span>
```

Semua variabel katalog dicetak **tanpa escaping**. Komentar di berkas ("do not call themeEscape() here") memang menjelaskan helper tema belum dimuat di rute sitasi — tetapi itu bukan alasan untuk tidak memakai `htmlspecialchars()` bawaan PHP.

**Dampak:** setiap data katalog yang mengandung HTML/JS (input staf yang lalai/jahat, hasil impor MARC dari sumber luar, rekaman Z39.50/SRU) akan **dieksekusi sebagai script** di popup/halaman sitasi — halaman yang justru sering dibuka dari hasil pencarian publik.

**Perbaikan (wajib, < 15 menit):**

```php
<?php
$e = fn($v) => htmlspecialchars((string)$v, ENT_QUOTES, 'UTF-8');
?>
<span class="authors"><?= $e($authors_string) ?></span>
<span class="title"><em><?= $e($title) ?></em> ...
```

Catatan: `$theme_dir` di baris ±33 juga di-`echo` mentah dari `$sysconf['template']['theme']` — bungkus dengan `htmlspecialchars()` juga (risiko rendah karena nilai admin, tapi gratis untuk diamankan).

### K-02 — Host-header injection di URL QR & bagikan

**Lokasi:**

- `detail_template.php:35-42` (`$host = $_SERVER['HTTP_HOST'] ?? ...`)
- `parts/_other.php:69-74` (pola identik untuk tombol Share konten)

**Bukti:**

```php
$host = $_SERVER['HTTP_HOST'] ?? $_SERVER['SERVER_NAME'] ?? 'localhost';
...
$detail_share_url = $scheme . $host . $swb_clean . 'index.php?p=show_detail&id=' . $biblio_id_safe;
```

`HTTP_HOST` sepenuhnya dikendalikan penyerang. URL ini dirender ke QR code SVG, kolom "salin tautan", dan tombol Share.

**Dampak:** penyerang dapat membuat QR code/tautan OPAC menunjuk ke domain phishing (`https://slims-palsu.example/...`) dan jika respons di-cache (proxy/CDN), racun menyebar ke pengunjung lain.

**Perbaikan (wajib):** buat satu helper host terpusat dan pakai di kedua tempat:

```php
function themeCurrentHost(array $source = null) {
  $host = strtolower(trim((string)($_SERVER['HTTP_HOST'] ?? '')));
  // Hanya izinkan host yang cocok dengan konfigurasi; fallback aman.
  $allowed = strtolower(trim((string)(getenv('SLIMS_CANONICAL_HOST') ?: '')));
  if ($allowed !== '' && hash_equals($allowed, preg_replace('/:\d+$/', '', $host))) {
    return $host;
  }
  if (preg_match('/^[a-z0-9.-]+(:\d+)?$/i', $host)) {
    return $host; // atau: return $source['canonical_host'] bila tersedia
  }
  return 'localhost';
}
```

Minimal: validasi format host + tolak karakter aneh, dan gunakan `themeRequestIsHttps()` yang sudah ada (lihat T-tambahan S-16: kedua lokasi ini tidak memakai helper HTTPS terpusat sehingga salah skema di balik TLS-terminating proxy).

## 4. Temuan Tinggi 🟠

### T-01 — `themeInjectCspNonceToScripts()` merusak JavaScript core

**Lokasi:** `helpers/security.php` (±baris 199-233). Dipakai di `parts/_other.php`, `parts/member/member_layout.php` (2×), dan halaman konten.

Fungsi ini tidak hanya menyuntik nonce — ia **membungkus setiap inline `<script>` dalam closure `DOMContentLoaded`**:

```php
$code = "document.addEventListener('DOMContentLoaded', function() {\n  " . $code . "\n});";
```

**Dampak nyata:**

1. Deklarasi `const`/`let`/`class` tingkat atas yang tadinya global menjadi lokal-fungsi → **script berikutnya yang memakainya melempar `ReferenceError`** dan fitur core/plugin rusak misterius.
2. Script yang memang harus jalan segera (sebelum DOMContentLoaded) tertunda.
3. Regex `/<script\b([^>]*)>(.*?)<\/script>/is` gagal jika kode mengandung string `"</script>"` di dalam literal JS.
4. Pengecualian "diawali `function foo(`" tidak mencakup `const foo = ...`, arrow-IIFE, dan `var`.

**Perbaikan:** suntik nonce saja, jangan bungkus. Penundaan eksekusi seharusnya ditangani dengan atribut `defer` pada script eksternal (footer sudah contestants), bukan me-rewrite semantik kode orang lain:

```php
// Hanya tambah nonce; JANGAN ubah isi kode.
return preg_replace_callback(
  '/<script\b([^>]*)>/i',
  fn($m) => stripos($m[0], 'nonce=') === false
    ? '<script nonce="' . themeEscape($nonce) . '"' . $m[1] . '>'
    : $m[0],
  $html
);
```

### T-02 — `csrf_token` bocor ke URL ganti bahasa

**Lokasi:** `parts/_navbar.php:171` (`$lang_params = $_GET ?? [];`)

Semua parameter GET — termasuk `csrf_token` — disalin ke setiap tautan bendera bahasa. Token CSRF lalu tersimpan di riwayat browser, log server/proxy, dan header `Referer`.

Ironisnya, `parts/_result-search.php:71-73` **sudah melakukan hal yang benar** (`array_filter` membuang `csrf_token`) — jadi ini inkonsistensi internal, bukan ketidaktahuan.

**Perbaikan (1 baris):**

```php
$lang_params = array_diff_key($_GET ?? [], ['csrf_token' => true]);
$lang_params['select_lang'] = $lang_code;
```

Terapkan pola yang sama di setiap tempat yang me-`http_build_query($_GET)` (audit: `_result-search.php:260` masih menyertakan token secara eksplisit untuk form view — itu memang disengaja untuk POST, biarkan).

### T-03 — Bypass `themeSanitizeMetadata()`

**Lokasi:** `helpers/security.php` (±baris 500-516).

1. `<meta http-equiv="refresh" content="0;url=javascript:...">` **tidak diblokir** — vektor XSS/phishing klasik lewat metadata core.
2. Regex penghapus `on*`/`javascript:` mensyaratkan atribut ber-quote (`["']`) — varian tanpa quote (`<link href=javascript:alert(1)>`) lolos.

**Perbaikan:** pendekatan allowlist atribut, bukan denylist pola:

```php
// Hanya izinkan atribut aman pada <meta>/<link>, tolak http-equiv=refresh.
$clean = preg_replace_callback('/<(meta|link)\b([^>]*)>/i', function ($m) {
  // parse atribut, pertahankan hanya: name|property|content|rel|href|media|sizes|...
  // tolak nilai dengan skema javascript:/data:text/html & http-equiv refresh
}, $clean);
```

### T-04 — `getRandomBiblio()` salah logika (koleksi "hilang" + tidak acak)

**Lokasi:** `helpers/core.php` (±baris 215-260).

```sql
... GROUP BY biblio_author.biblio_id LIMIT ?, ?
```

- `LEFT JOIN` menghasilkan `biblio_author.biblio_id = NULL` untuk **semua biblio tanpa penulis** → semuanya runtuh menjadi **satu grup** → judul-judul itu praktis tidak pernah tampil.
- "Random" sebenarnya hanya slice sekuensial dari offset acak, tanpa `ORDER BY` (nondeterministik antar replika/MySQL versi), dan `COUNT(*)` dihitung dari tabel `biblio` sementara offset diterapkan ke jumlah grup — bisa keluar jangkauan → hasil kosong.

**Perbaikan:** untuk limit kecil (≤12), cara paling benar & sederhana:

```sql
SELECT b.biblio_id, b.title, b.image FROM biblio b
ORDER BY RAND() LIMIT ?
```

dengan cache file 5–15 menit agar tidak membebani DB. Atau: ambil N `biblio_id` acak via `MAX(biblio_id)` + sampling, lalu hydrate.

### T-05 — Query topik tidak portabel ke MySQL strict (`ONLY_FULL_GROUP_BY`)

**Lokasi:** `helpers/core.php` — `getPopularTopic()` dan `getLatestTopic()`.

```sql
SELECT mt.topic ... GROUP BY bt.topic_id
```

`mt.topic` tidak independen-fungsional terhadap `bt.topic_id` menurut aturan MySQL 5.7+ default → **error 1055** pada instalasi MySQL strict (lolos di MariaDB karena `sql_mode` default-nya longgar — menjelaskan kenapa bug ini tidak terlihat selama ini).

**Perbaikan:** `GROUP BY mt.topic_id, mt.topic` (atau `ANY_VALUE(mt.topic)`).

### T-06 — Endpoint suggest rapuh terhadap tipe `$dbs`

**Lokasi:** `index_template.inc.php:21` — `isset($dbs) && $dbs instanceof mysqli`.

Di SLiMS, `$dbs` adalah objek wrapper database; jika pada suatu rilis ia bukan turunan `mysqli`, seluruh fitur autocomplete **diam-diam mengembalikan `[]`** tanpa error/log. Sudah ada preseden duck-typing di template ini (`method_exists($dbs, 'prepare')` di `_other.php`, `detail_fields.php`).

**Perbaikan:**

```php
if ($query_length >= 2 && isset($dbs) && is_object($dbs) && method_exists($dbs, 'prepare')) {
```

(Perlu smoke test di target SLiMS untuk konfirmasi perilaku aktual — lihat §10.)

## 7. Saran Upgrade

### 7.1 Performa (dampak terbesar, usaha kecil–sedang)

1. **Pangkas CSS ±870 KB**: hapus/trim `foundation.css` bila duplikat Bootstrap; minify `opac-pages.css` (276 KB, 9453 baris) & `theme-dark.css` (148 KB); audit unused rules (Coverage DevTools); code-split per halaman (visitor/detail/search).
2. **Lazy-load Theme Viewer**: `palette_switcher.php` (±56 KB HTML) + `theme_viewer.js` (136 KB) + `theme_drawer.js` dimuat di setiap halaman saat aktif (default ON) — muat via AJAX hanya saat drawer dibuka. Penghematan ±200 KB/halaman untuk pengunjung biasa.
3. **`defer` skrip footer** yang aman (lihat R-03) + `preload` CSS kritis; ukur dengan Lighthouse (target: LCP < 2.5 s di 4G).
4. **Kurangi 6 MB flag SVG** (R-06) → clone/checkout lebih cepat, rilis zip mengecil drastis.
5. **Cache lapisan template**: memo statis untuk `themeGetDisplayItems`, query libinfo floating, dan `filemtime` versi aset (kumpulkan sekali per request).

### 7.2 Keamanan (pertahanan berlapis)

1. **CSP bertahap**: (a) hapus wildcard `https:` → allowlist domain (Aladhan API, Maps embed, `wa.me`); (b) pindahkan inline event/script ke file + nonce; (c) target akhir: tanpa `unsafe-inline`/`unsafe-eval`. Nonce infrastructure sudah ada — tinggal manfaatkan penuh.
2. **Helper host terpusat** (K-02) dipakai di semua pembentuk URL absolut (QR, share, OG, canonical).
3. **Audit GET bermutasi**: pastikan tidak ada aksi tulis lewat GET (suggest read-only — sudah benar); semua form tulis memakai CSRF core.
4. **Sanitasi allowlist** untuk metadata (T-03) dan ikuti pola yang sama di calon titik baru.
5. **Dependency hygiene terjadwal**: Dependabot/Renovate untuk jQuery/Bootstrap/Axios/Vue (repo saat ini tanpa manifest — mulai dari `package.json` + lockfile meski aset di-vendor).

### 7.3 Kualitas kode & DX

1. **CI minimal** (GitHub Actions): `php -l` semua PHP, `phpstan` level dasar, `eslint`/`prettier` untuk JS tema (kecualikan `*.min.js`), dan `stylelint` untuk CSS kustom.
2. **Standar**: `.editorconfig` + PSR-12; hapus dead code (`$test_mode`, fallback `dirname(__DIR__)` ganda, `classic.php` double-include guard).
3. **Test parser murni**: `visitor steps`, `navbar menu`, `topic items`, `whatsapp template`, `parallel title` adalah fungsi murni — ideal untuk PHPUnit; cegah regresi format TInfo yang sudah kompleks.
4. **Kontrak versi**: `README` menyatakan minimum (PHP ≥ 8.1, SLiMS ≥ 9.6, MySQL 5.7+/MariaDB 10.3+) + matriks uji; `CHANGELOG.md` tiap rilis; `tinfo` export contoh untuk instalasi baru.
5. **Netralkan default** (S-10) + sediakan preset "Contoh UI" terpisah bila perlu — template publik tidak boleh berkiblat ke satu institusi.

### 7.4 Aksesibilitas & UX lanjutan

1. `aria-current="page"` pada item nav aktif; sinkronkan `aria-expanded`/`aria-hidden` collapse navbar dengan JS.
2. Hormati `prefers-reduced-motion` di semua animasi canvas/kursor (verifikasi `motion_lifecycle.js` mencakup semuanya).
3. **JSON-LD `Book` schema** di halaman detail (SEO + rich result) — murah, berdampak.
4. Stylesheet cetak untuk detail/sitasi/kartu anggota (`@media print`).
5. Dokumentasikan keputusan "tanpa Service Worker" di README (review lama sudah menyarankan; belum ada) agar tidak dianggap bug.

### 7.5 Fitur yang layak dipertimbangkan

- Mode kiosk visitor: virtual keyboard & timeout sesi; suara antrean sudah ada — lengkapi panduan perangkat.
- Sitemap XML OPAC & robots yang sadar `p=` (nä Havre: diskusikan dengan core).
- Statistik unduhan attachment? (butuh dukungan core — ajukan upstream).
- Storybook/galeri komponen dari `theme-components.css` agar kontributor tidak menebak class.

## 8. Kekuatan yang Patut Dipertahankan

- **Disiplin escaping** di 95%+ permukaan: `themeEscape`/`themeSafeInt`/`themeSafeMenuUrl` dipakai konsisten — fondasi yang membuat K-01/K-02 jadi pengecualian, bukan pola.

- **Sanitasi CSS kustom** (`themeSanitizeCustomCss`) dan **sanitasi aset core** (`themeSanitizeCoreAssetTags`) adalah pekerjaan tingkat framework — pertahankan & uji regresinya.
- **Aset kondisional per halaman** (Vue, Masonry, ion-rangeSlider, detail/result JS) + `defer` di sebagian besar skrip tema.
- **Aksesibilitas teladan**: skip-link, label tersembunyi, `aria-pressed`, target sentuh, fokus keyboard autocomplete (`Ctrl+K`!).

- **Feature flags** (`theme_feature_flags.php`) untuk rollout bertahap — pola yang jarang ada di template SLiMS.
- **Mekanisme simpan Theme Viewer** dirancang hati-hati: probe otorisasi via form admin asli, kirim ulang `FormData` admin (termasuk token), lalu verifikasi round-trip sebelum klaim sukses. Tinggal batasi paparan nilai TInfo (S-07).
